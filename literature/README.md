# Citation-source custody

`CITATION_SOURCES.tsv` records the sources inspected for methodological and
state-of-the-art claims. It includes stable identifiers, retrieval sources,
the format examined, and the SHA-256 digest of the locally retained snapshot.

Complete literature PDFs, HTML articles, and XML articles are intentionally
not committed or distributed here. Their absence is deliberate: an authorized
local copy can be matched to the recorded digest without putting copyrighted
source bytes in Git.
