# `data/` — metadata and derived tables

Everything in this directory is either a small metadata table that
ships with the repository or a derived bioinformatic output that is
small enough (under ~50 MB) to version with git. Large derived
artefacts that don't fit these limits are gitignored and documented
below with regeneration instructions.

## Contents

### `data/climate/`
- `daily_weather.tsv` — daily NASA POWER records per site (3.3 MB).
  Columns: `date`, `SiteNum`, `lat`, `lon`, `T2M`, `T2M_MAX`,
  `T2M_MIN`, `PRECTOTCORR`, `WS10M`, `RH2M`, `ALLSKY_SFC_UV_INDEX`,
  `ALLSKY_SFC_SW_DWN`, `GWETTOP`.
  Produced by `scripts/fetch_nasa_power.py`.
- `monthly_weather_averages.tsv` — per-site monthly aggregates of
  the above (132 KB).

### `data/geochemistry/`
- `xrf_lab_table_filtered.tsv` — Trip 5 XRF panel, 158 samples × 33
  elements, after QC filter for elements with < 50% zeros.
  Source: internal Kyra XRF spectrometer runs. Columns: `sample_id`,
  `Site`, `Compartment`, then one column per element (`Al`, `Si`,
  `P`, `S`, `Cl`, `K`, `Ca`, `Ti`, `V`, `Cr`, `Mn`, `Fe`, `Ni`,
  `Cu`, `Zn`, `Br`, `Sr`, etc.) in parts-per-million.

### `data/geodata/`
- `trip{1..5}_geodata.tsv` — per-trip site metadata: site number,
  latitude, longitude, elevation, habitat class, sampling date,
  compartment codes. These are the source of truth for coordinates
  used by the climate / topography / NDVI fetchers.

### `data/taxonomy/`
- `taxonomy-trips1-5.tsv` — ASV → 7-rank SILVA 138.2 lineage table
  (~38 MB). Columns: `ASV_ID`, `Domain`, `Phylum`, `Class`,
  `Order`, `Family`, `Genus`, `Species`. Produced by nf-core/Ampliseq
  DADA2 classifier against SILVA v138.2.
- **NOT IN REPO**:
  - `feature-table-trips1-5.tsv` (1.7 GB). Sample × ASV count
    matrix. Regenerate from raw reads with
    `nf-core/ampliseq -profile ... --FW_primer CCTACGGGNGGCWGCAG
    --RV_primer GGACTACNVGGGTWTCTAAT`, or fetch from the companion
    KG SPARQL endpoint described in the data paper.
  - `ASV_seqs-trips1-5.fasta` (155 MB). ASV representatives. Same
    provenance as the feature table.

### `data/functional/picrust2/`
- `path_abun_unstrat.tsv` (7 MB) — PICRUSt2 MetaCyc pathway
  abundance table, 462 pathways × samples.
- `path_abun_unstrat_descriptions.tsv` (7 MB) — same, with
  human-readable descriptions appended.
- `path_abun_unstrat_relative_pct.tsv` (7 MB) — relative abundance
  (%) equivalent of the above.
- `metagenome_pred_metagenome_unstrat.tsv` (23 MB) — PICRUSt2
  unstratified gene-content predictions.
- `sample_mapping.tsv` — sample-ID cross-walk used by PICRUSt2.
- `README.md` — upstream PICRUSt2 run parameters (HMMER cutoff,
  MaxNSTI).
- **NOT IN REPO**:
  - `KO_predicted.tsv` (4.4 GB) — KO-level PICRUSt2 predictions.
    Regenerate with `picrust2_pipeline.py --placement_tool epa-ng`.
  - `EC_predicted.tsv` (358 MB) — EC-level PICRUSt2 predictions.
    Same regeneration route.
  - `ko_pred_metagenome_unstrat.tsv` (189 MB) — unstratified KO
    table.

### `data/functional/picrust2/merged/`
Merged per-trip PICRUSt2 outputs used as waypoints by
`06_function.qmd`; regenerated by the PICRUSt2 run (see above).

### `data/functional/picrust2/trip{1-4,5}/`
Per-trip PICRUSt2 intermediate runs used for trip-level redundancy
comparisons.

## Regenerating large tables

All large artefacts are deterministic functions of the raw reads at
ENA `PRJEB106069`. The single command

```bash
nextflow run nf-core/ampliseq \
  -profile unimatrix \
  --input samplesheet.csv \
  --FW_primer CCTACGGGNGGCWGCAG \
  --RV_primer GGACTACNVGGGTWTCTAAT \
  --dada2_ref_taxonomy silva=138.2 \
  --min_len_asv 400 --max_len_asv 440 \
  --illumina_novaseq --multiple_sequencing_runs
```

regenerates `feature-table-trips1-5.tsv`, `ASV_seqs-trips1-5.fasta`,
and `taxonomy-trips1-5.tsv`. PICRUSt2 outputs follow via

```bash
picrust2_pipeline.py \
  -s ASV_seqs-trips1-5.fasta \
  -i feature-table-trips1-5.tsv \
  -o picrust2_out --placement_tool epa-ng -p 16
```
